Giới thiệu

Định hướng phát triển chuyên sâu theo mô hình Hybrid QC Engineer — lấy Manual Testing làm nền tảng và ứng dụng Automation thực tế.

Professional Summary

Phân tích yêu cầu nghiệp vụ, thiết kế và thực thi test case; thực hiện Functional, API và Database Testing. Trực tiếp thiết kế Test Automation Framework theo POM, phát triển bộ API/E2E tests và tích hợp GitHub Actions.

Giá trị mang lại

  • Nhận diện và kiểm soát rủi ro sớm.
  • Chuẩn hóa test case và Regression Testing.
  • Framework có khả năng tái sử dụng, bảo trì và mở rộng.
  • Kết hợp kiểm thử thủ công và tự động phù hợp phạm vi.
